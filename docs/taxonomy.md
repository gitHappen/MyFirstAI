# Classification tree

The website groups animal records by Kingdom, Phylum, Class, Order, Family, Genus, and Species. Each branch expands with native keyboard-accessible disclosure controls. Animal names open their records. Blank ranks appear as **Unclassified** so uncertainty is visible throughout the tree. This is a rank-based taxonomy browser, not a phylogenetic tree or a claim about particular common ancestors.

Initial broad placements follow the candidate common groups, not verified specimen identifications:

- All candidates belong to Animalia.
- Insects: Arthropoda / Insecta.
- Spiders: Arthropoda / Arachnida.
- Centipedes: Arthropoda / Chilopoda.
- Millipedes: Arthropoda / Diplopoda.
- Pill bugs: Arthropoda; class left blank because higher crustacean ranks vary among classifications.
- Lizards: Chordata / Reptilia, using the traditional educational class label.
- Worms: phylum and lower ranks unknown; the common term spans different groups.

Orders and lower ranks are deliberately blank until supported identifications are supplied. Broad names such as “wasps and hornets” may represent multiple taxa. Split these into separate specimen or species records as evidence becomes available.

Reference resources for checking these general placements and later identification:

- [Animal Diversity Web, University of Michigan](https://animaldiversity.org/): search the relevant scientific group and its classification.
- [Catalogue of Life](https://www.catalogueoflife.org/): check accepted names and current classification when identifying a specimen.

These are classification resources, not evidence of a personal sighting. Taxonomies can differ and change; include specific identification citations in the animal’s sources when refining its ranks.
